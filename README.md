# NL4OPT_VRP
NL4OPT is a Natural Language Processing (NLP) based project that converts natural language descriptions of optimization problems into mathematical models. It identifies decision variables, objective functions, and constraints, simplifying the formulation of Linear Programming problems and making optimization more accessible.

🚀 I have integrated MCP, LLMs, and Solomon's Benchmarking Problems to develop an LLM-based Optimization Solver.

💡 Users can simply provide a problem description in natural language along with the required data, and the solver will formulate and solve the optimization problem.

⚙️ Currently, SCIP is implemented as the optimization engine, with the flexibility to integrate other solvers such as IBM ILOG CPLEX, Gurobi, and more.

🚚 I am developing this solver specifically for Supply Chain Network Optimization, focusing on solving complex Vehicle Routing Problems (VRPs).
